# 🚀 Portfolio Personal — Full Stack Developer & Técnico en Electrónica

Un portfolio web moderno, rápido y responsive construido con el ecosistema de **Next.js**, **Tailwind CSS**, **Framer Motion**, **Magic UI** y **Shadcn UI**. Diseñado para presentar mis proyectos y especialización como **Técnico en Electrónica**, especializado en **programación IoT** y **desarrollo Backend**, junto a soluciones **Full Stack**.

## ✨ Características Principales

- 🎨 **Diseño Moderno & Minimalista:** Estética oscura elegante basada en componentes de alta calidad.
- 🌌 **Magic UI & Framer Motion:** Implementación del componente `AuroraText` y animaciones fluidas al hacer scroll.
- ⚡ **Perfil Técnico Integrado:** Muestra el equilibrio entre el mundo del hardware (Técnico en Electrónica & IoT) y el software (Backend de alto rendimiento & Full Stack Web).
- 🛠️ **Arquitectura Modular:** Componentes UI aislados y reutilizables creados con **Shadcn UI**.
- 📁 **Gestión Dinámica de Proyectos:** Colección de proyectos centralizada con enlaces a repositorios de GitHub, Demos interactivas, categorías e imágenes alojadas en Cloudinary.
- 📱 **Totalmente Responsive:** Adaptado para una navegación fluida en dispositivos móviles, tablets y escritorio.

## 🚀 Instalación y Configuración Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/alan/portfolio.git
   cd my-app
   ```

2. **Instalar Dependencias:**
   ```bash
   npm install
   ```

3. **Ejecutar el Servidor de Desarrollo:**
   ```bash
   npm run dev
   ```

4. **Abrir en el navegador:**
   Visita `http://localhost:3000` para ver la aplicación localmente.
