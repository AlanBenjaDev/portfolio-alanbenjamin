# 🚀 Portfolio Personal — Full Stack Developer

Un portfolio web moderno, rápido y responsive construido con el ecosistema de **Next.js**, **Tailwind CSS**, **Framer Motion**, **Magic UI** y **Shadcn UI**. Diseñado para presentar mis proyectos como desarrollador Full Stack, destacar mi experiencia y facilitar el contacto directo.

## ✨ Características Principales

- 🎨 **Diseño Moderno:** Basado en la estética minimalista y oscura de la plantilla DevPro (Aceternity UI).
- 🌌 **Magic UI Integration:** Implementación del componente `AuroraText` para titulares dinámicos.
- ⚡ **Desempeño Extremo:** Arquitectura impulsada por **Next.js App Router** y componentes con tipado estricto en **TypeScript**.
- 🛠️ **Arquitectura Modular:** Componentes UI aislados y reutilizables creados con **Shadcn UI**.
- 📁 **Gestión Dinámica de Proyectos:** Colección de proyectos centralizada con enlaces a repositorios de GitHub, Demos interactivas e imágenes alojadas en Cloudinary.
- 📱 **Totalmente Responsive:** Adaptado para una navegación fluida en dispositivos móviles, tablets y escritorio.

## 🛠️ Tech Stack

**Frontend:**
- [Next.js](https://nextjs.org/) — React Framework para Producción
- [React](https://react.dev/) — Librería para Interfaces de Usuario
- [Tailwind CSS](https://tailwindcss.com/) — Framework de CSS Orientado a Utilidades
- [Framer Motion](https://www.framer.com/motion/) — Librería de Animaciones
- [Shadcn UI](https://ui.shadcn.com/) & [Magic UI](https://magicui.design/) — Componentes de UI

**Herramientas & Deployment:**
- [TypeScript](https://www.typescriptlang.org/) — Superset de JavaScript con Tipado Estático
- [Cloudinary](https://cloudinary.com/) — CDN e Infraestructura de Imágenes
- [Vercel](https://vercel.com/) — Plataforma de Hosting y Despliegue

## 🚀 Instalación y Configuración Local

Si querés clonar este proyecto y correrlo en tu máquina local, seguí estos pasos:

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/tu-usuario/tu-repositorio.git](https://github.com/tu-usuario/tu-repositorio.git)
   cd tu-repositorio

2. **Instalar Dependencias:**

    npm install
    # o
   pnpm install
   # o
   yarn install

3. **Ejecutar el Servidor de Desarrollo**
   **npm run dev**

4. **Abrir en el navegador**
    **http://localhost:3000 para ver la pagina  y desarrollar.**
